Quick Commands
══════════════

Standard Example:
  cd example
  flutter run

Marketplace Example:
  cd example_marketplace
  flutter run

Run Both:
  # Terminal 1
  cd example && flutter run -d chrome --web-port=8080
  
  # Terminal 2
  cd example_marketplace && flutter run -d chrome --web-port=8081

Decision Tree
═════════════

Need multi-seller functionality?
├─ NO  → Use example/
│        • Simpler setup
│        • Standard Magento only
│        • Perfect for learning
│
└─ YES → Use example_marketplace/
         • Full marketplace features
         • Requires module-marketplace
         • Advanced functionality


═══════════════════════════════════════════════════════════════════

Environment Configuration
═════════════════════════

example/.env:
  MARKETPLACE=false
  MAGENTO_API_URL=https://your-store.com/

example_marketplace/.env:
  MARKETPLACE=true
  MAGENTO_API_URL=https://your-marketplace.com/
  ENABLE_SELLER_REGISTRATION=true
  ENABLE_SELLER_DASHBOARD=true
  ENABLE_SELLER_RATINGS=true
