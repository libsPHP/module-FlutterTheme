## 🎯 Как Использовать

### Шаг 1: Настройка API
1. Откройте вкладку **Config** (Settings)
2. Введите URL вашего Magento магазина
3. Или нажмите "Use Default Demo" для демо-магазина
4. Нажмите "Save & Initialize"

**Демо URL по умолчанию**: `https://luma-demo.scandipwa.com/`

### Шаг 2: Аутентификация (опционально)
1. Откройте вкладку **Auth**
2. Войдите или зарегистрируйтесь
3. Некоторые функции требуют авторизации (корзина, профиль)

### Шаг 3: Изучите Функции

#### Просмотр Продуктов
1. Перейдите на **Products**
2. Используйте поиск для фильтрации
3. Нажмите на товар для просмотра
4. Добавьте в корзину (требуется вход)

#### Навигация по Категориям
1. Откройте **Categories**
2. Выберите категорию
3. Просмотрите подкатегории
4. Посмотрите товары в категории

#### Управление Корзиной
1. Войдите в систему
2. Откройте **Cart**
3. Измените количество товаров
4. Удалите ненужные товары

#### RADA Формат (Офлайн)
1. Откройте **RADA**
2. Экспортируйте категорию
3. Импортируйте RADA файл
4. Используйте предзагруженные данные
