Flutter Magento SDK - Пример приложения

Демонстрационное приложение Flutter SDK для интеграции с Magento 2 eCommerce платформой через GraphQL API.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:

🛍️ Управление каталогом
• Загрузка и отображение продуктов из Magento
• Поиск товаров по названию и описанию
• Просмотр категорий и подкатегорий
• Отображение изображений, цен и описаний
• Поддержка специальных цен и скидок

👤 Аутентификация
• Регистрация новых пользователей
• Вход в систему по email и паролю
• Безопасное хранение токенов
• Управление профилем пользователя

🛒 Корзина покупок
• Добавление товаров в корзину
• Изменение количества товаров
• Удаление позиций
• Подсчет итоговой стоимости
• Синхронизация с Magento API

⚙️ Гибкая настройка
• Подключение к любому Magento 2 магазину
• Поддержка .env файлов для конфигурации
• Быстрое переключение между магазинами
• Проверка соединения с API

🚀 Современные технологии
• GraphQL API для быстрой загрузки данных
• Архитектура Provider для управления состоянием
• Адаптивный Material Design интерфейс
• Поддержка iOS и Android

ДЛЯ РАЗРАБОТЧИКОВ:

Это пример приложения демонстрирует возможности Flutter Magento SDK. Используйте его как основу для создания собственных мобильных приложений для Magento магазинов.

SDK предоставляет готовые решения для:
- Работы с продуктами и категориями
- Управления корзиной и заказами
- Аутентификации пользователей
- Обработки платежей
- И многого другого

Полная документация и исходный код доступны на GitLab.

ТЕСТИРОВАНИЕ:

Приложение поставляется с предустановленными demo-магазинами для тестирования всех функций без необходимости настройки собственного Magento сервера.

ТРЕБОВАНИЯ:

• iOS 11.0 или новее
• Подключение к интернету для работы с Magento API
