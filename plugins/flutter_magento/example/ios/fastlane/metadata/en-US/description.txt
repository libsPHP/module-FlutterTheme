Flutter Magento SDK - Example App

Demo application showcasing Flutter SDK for Magento 2 eCommerce platform integration via GraphQL API.

KEY FEATURES:

🛍️ Catalog Management
• Load and display products from Magento
• Search products by name and description
• Browse categories and subcategories
• Display images, prices, and descriptions
• Support for special prices and discounts

👤 Authentication
• User registration
• Login with email and password
• Secure token storage
• User profile management

🛒 Shopping Cart
• Add products to cart
• Update product quantities
• Remove items
• Calculate totals
• Sync with Magento API

⚙️ Flexible Configuration
• Connect to any Magento 2 store
• .env files support for configuration
• Quick switching between stores
• API connection testing

🚀 Modern Technologies
• GraphQL API for fast data loading
• Provider architecture for state management
• Adaptive Material Design interface
• iOS and Android support

FOR DEVELOPERS:

This example app demonstrates Flutter Magento SDK capabilities. Use it as a foundation for building your own mobile apps for Magento stores.

The SDK provides ready-to-use solutions for:
- Working with products and categories
- Cart and order management
- User authentication
- Payment processing
- And much more

Full documentation and source code available on GitLab.

TESTING:

The app comes with pre-configured demo stores for testing all features without setting up your own Magento server.

REQUIREMENTS:

• iOS 11.0 or later
• Internet connection for Magento API access
