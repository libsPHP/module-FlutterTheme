## What This Feature Does

The Profile screen is your personal account hub where you can manage your personal information, saved addresses, view shopping statistics, and customize app settings.

**Key Benefits**:
- Edit your personal information anytime
- Save multiple addresses for fast checkout
- View your order history and spending
- Customize notifications and preferences

---

## How It Works

**In Simple Terms:**

Think of Profile like your personal file cabinet:

1. **Profile Tab** = Your ID card
   - Name, email, phone
   - Easy to update
   - Saved for future orders

2. **Addresses Tab** = Your address book
   - Save home, work, other addresses
   - Quick select at checkout
   - No need to type every time

3. **Statistics Tab** = Your shopping report card
   - Total orders
   - Money spent
   - Activity history

4. **Settings Tab** = Your control panel
   - Notifications on/off
   - Language, currency
   - Privacy controls

## Quick Example

### Example: Updating Your Profile

**Goal**: Change phone number

**Steps**:
1. Tap "Profile" in bottom navigation
2. Make sure "Profile" tab is selected
3. Tap "Edit Profile"
4. Find "Phone" field
5. Enter new number: +1-555-123-4567
6. Tap "Save Changes"
7. You'll see: "Profile updated successfully!"

**Result**: Your new phone number is saved!

---

### Example: Adding a New Address

**Goal**: Save work address

**Steps**:
1. Go to Profile → Addresses tab
2. Tap "+ Add" button
3. Fill in the form:
   - First Name: John
   - Last Name: Doe
   - Street: 456 Business Ave
   - City: New York
   - ZIP: 10002
   - Phone: +1-555-987-6543
4. Tap "Save Address"

**Result**: Work address saved! Select it at checkout.

## Common Questions

### How do I edit my name?
Go to Profile tab → Tap "Edit Profile" → Change name fields → Tap "Save"

### Can I save multiple addresses?
Yes! Save as many addresses as you need (home, work, family, etc.)

### How do I delete my account?
Go to Settings tab → Scroll to "Danger Zone" → Tap "Delete Account" → Confirm

### Where do I see my orders?
Statistics tab shows order count. For full order history, tap "View Orders"

### Can I change the app language?
Yes! Settings → Language → Select your preferred language

### Are my changes saved automatically?
Yes, when you tap "Save" or "Update", changes are saved immediately
