## Режим работы Magento Marketplace

У категории или продукта может быть дополнительный атрибут `seller_id`, тогда Magento работает в режиме маркетплейса.

### Как это работает

Когда в системе присутствует атрибут `seller_id` у категорий или продуктов:

1. **Режим маркетплейса активирован** - система автоматически поддерживает мультиселлерную архитектуру
2. **Продукты привязаны к продавцам** - каждый продукт может иметь своего продавца через `seller_id`
3. **Категории продавцов** - категории также могут быть связаны с конкретными продавцами
4. **Управление продавцами** - используйте функционал из `flutter_magento_marketplace` для работы с продавцами

### Использование

```dart
import 'package:flutter_magento/flutter_magento.dart';

// Проверка наличия seller_id у продукта
final product = await productApi.getProduct(productId);
final sellerId = product.customAttributes
    ?.firstWhere((attr) => attr.attributeCode == 'seller_id')
    ?.value;

if (sellerId != null) {
  // Режим маркетплейса активен
  // Загрузить информацию о продавце
  final seller = await sellerService.getSeller(int.parse(sellerId.toString()));
}
```

## Формат .rada

### Описание формата

`.rada` - это специальный формат для хранения и обмена данными категорий Magento, включая структуру категорий, продукты, изображения, отзывы и переводы.

### Структура формата

Файл .rada представляет собой ZIP-архив со следующей структурой:

```
example.rada (ZIP archive)
├── manifest.json          # Метаданные формата и версия
├── data.json             # Основные данные категории и продуктов
├── assets/               # Изображения
│   ├── categories/       # Изображения категорий
│   │   └── {id}.{ext}
│   └── products/         # Изображения продуктов
│       └── {sku}/
│           └── {filename}.{ext}
└── l10n/                 # Переводы
    ├── en.json
    ├── ru.json
    └── {locale}.json
```

### manifest.json

Содержит метаданные о RADA-файле:

```json
{
  "version": "1.0",
  "format": "rada",
  "createdAt": "2025-10-17T12:00:00Z",
  "createdBy": "flutter_magento",
  "source": {
    "storeUrl": "https://example.com",
    "categoryId": 123,
    "categoryName": "Electronics"
  },
  "stats": {
    "categoriesCount": 10,
    "productsCount": 50,
    "imagesCount": 150,
    "reviewsCount": 25,
    "localesCount": 2
  },
  "checksums": {
    "main": "sha256:...",
    "assets": "sha256:...",
    "l10n": "sha256:..."
  }
}
```

Основные данные категорий и продуктов:

      "id": 1,

### Использование формата .rada

#### Экспорт данных

```dart
import 'package:flutter_magento/flutter_magento.dart';

// Создать экспортер
final exporter = RadaExporter(magentoApiClient);

// Экспортировать категорию со всеми данными
final radaFile = await exporter.exportCategory(
  categoryId: 123,
  includeSubcategories: true,
  includeProducts: true,
  includeReviews: true,
  includeImages: true,
  locales: ['en', 'ru'],
);

// Сохранить файл
await radaFile.saveTo('export/category_123.rada');
```

#### Импорт данных (Preload)

```dart
import 'package:flutter_magento/flutter_magento.dart';

// Создать импортер
final importer = RadaImporter();

// Импортировать из файла
final radaData = await importer.importFromFile('assets/preload.rada');

// Использовать как начальные данные
await preloadDataManager.loadFromRadaData(radaData);

// Или использовать с API
await magentoApiClient.preloadFromRada(radaData);
```

#### Работа с preload-данными

```dart
// Инициализация preload при запуске приложения
await RadaPreloadService.init(
  assetPath: 'assets/preload_data.rada',
  enableOfflineMode: true,
);

// Получение данных из preload
final categories = await preloadDataProvider.getCategories();
final products = await preloadDataProvider.getProducts(categoryId: 123);
```

### Преимущества формата .rada

1. **Портативность** - один файл содержит всё необходимое для работы
2. **Офлайн-поддержка** - можно работать без подключения к Magento
3. **Быстрый старт** - идеально для демо-версий и тестирования
4. **Версионирование** - манифест позволяет управлять совместимостью
5. **Локализация** - встроенная поддержка множественных переводов
6. **Целостность** - контрольные суммы для валидации данных
7. **Оптимизация** - изображения автоматически оптимизируются

### Ограничения

- Максимальный рекомендуемый размер файла: 500 МБ
- Поддерживаемые форматы изображений: JPG, PNG, WebP
- Рекомендуемая глубина вложенности категорий: до 5 уровней
- Изображения автоматически оптимизируются при экспорте

### Интеграция с маркетплейсом

При работе с маркетплейсом, формат .rada поддерживает атрибут `seller_id`:

```json
{
  "products": [
    {
      "id": 1,
      "sku": "PROD-001",
      "name": "Product from Seller",
      "customAttributes": [
        {
          "attributeCode": "seller_id",
          "value": "456"
        }
      ]
    }
  ]
}
```

Это позволяет:
- Экспортировать и импортировать данные продавцов
- Создавать preload-данные для маркетплейса
- Работать офлайн с маркетплейс-функционалом
